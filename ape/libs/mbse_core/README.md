# MBSE核心库

## PyPI包计划

将会在MBSE core项目完成核心程序开发后上传至PyPI。

## MBSE核心库简介

MBSE核心库的目标是建立MBSE结构的基础框架，使得包含：模型、数据库等的工程选择模块化；提供一致的API接口和系统工程规范。

该基础框架需要实现：兼容主流的可编程化模型（包含数学模型、工程模型），建立统一的信息管道（数据库）和输入输出窗口。

该框架的基础抽象结构可以参见：[通用抽象建模结构图](https://vscode.dev/github/Liphael/ReConsciousTy/blob/main/archive/%E6%89%A7%E8%A1%8C%E7%BA%B2%E9%A2%86.md#L219)
