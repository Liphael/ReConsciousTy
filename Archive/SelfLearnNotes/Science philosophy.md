### Definition & Demarcation

definition and demarcation is used to form a concept.

it is also similar to the different concept of "Extensional Definition" & "Intensional Definition".

within a loose concept, demarcation work is doing extersional definition, definition work is doing intensional definition.

demarcation is a essential part of definition, but it dont equal to definition itself, which also requires explaination of those left after demarcation.

the definition is typically divided into two existing forms, "Descriptive Definitions(Analytic Definitions)" & "Stipulative Definitions".

as Hempel presented in PHIOSOPHY OF NATURAL SCIENCE, this two forms serve for different purposes:
    1. describe the meaning of a word/term that already in use.
    2. stipulate particular meaning to a word/term.

usually we call the word a "term" after defining it when doing science. Descriptive definition serves for the first purpose, and stipulative definition serves for the second, that is the raw idea.

However, consider the case in teaching & learning: the terms already in use are still brand new to students, how to differentiate them in this situation? So we re-classify them in such way below:

    1. Descriptive definitions are plain encoding process that assign meaning to a word/sign, thus make it a term.
    2. Stipulative definitions are formalizing encoding process that not only assign meaning to a word/sign, but also stipulate the word/sign thus make it computable.

## Formalization of Science Philosophy

Formalization

a theory is typically(when we say typically, it means it otfen behave this way, not SHOULD or MUST) constructed by three layers: language, provements, synmatics.

### Language

### Meta Theory

Here we use "interpretation" to demarcate what a symbol represent, use "description" to demarcate what a object represent.

Description: A First-Order theory is a systematic theory that used to construct other theories on it. Usually it only contains variable "x", quantifier "a", predicate "f:".

under this frame, the objects are given by assigned variables, i.e. "Obj" is a encoded/assigned variable, when we talk about objects represent assigned variables, we say the objects are on the "Object language level". When we use objects to represent the concept of variable, concept of quantifier, etc. we say the objects are on the "Meta language level", or here called "First-Order language level", the particular objects are typically called "syntactic objects". 

- Encoding
    Encoding process(sometimes we say "naming", but naming is actually can include both encoding and defining/demarcating.) give the object a "code name", which give us a handle to represent it totally in an abstract way. encoding is different from defining because defining requires giving a certain connotation, i.e. a bunch of essential properties "p".

Arithmetization: the Meta language is the representation of First-Order theory, function as encoder of syntactic objects, thus make it arithmetized for computing. That is, encoding is for arithmetization.

the reason why we call it(encoding it) as object, not using set theory name "a element of the set" here is because we are at the meta language level, avoid directly using concepts particulatly built for computation(at object language level). That is, demarcating the rules of rules, doing formalization. And if it is needed we will repete the formalization, demarcate the meta-meta lang of meta lang, which canbe infinite if we require every level is proved consistant(no contradictions).

to encode the syntactic objects and introduce the inevitable self-referential result that encoding brings here, we should introduce the [Godel's Incompleteness Theorems](*) and [Godel numbering]().

- Godel's Incompleteness Theorems:
    - first incompleteness theorem: exist a TRUE sentence G in a consistant system T, cant prove it is TRUE by T itself. the sentence G is a self-referential sentence: "this sentence cant prove TRUE in system T".
    - second incompleteness theorem: a lemma/deduction of first incompleteness theorem, that "a sufficiently strong and consistant system T cannot prove the consistancy of itself within the system".<br>
    $$
    T \nvdash Con(T),
    \quad
    for~Con(T)~interprete~T~is~consistant
    $$
- Godel numbering

the fist incompleteness theorem is also examplified by Russell set, used to introduce the concept of "class" and "proper class" in set theory.
